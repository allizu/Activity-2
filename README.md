# `10` — ACTIVITY OBJECTIVE

This activity demonstrates how technical information can be transformed into **clear, organized, and visually engaging communication**.

Rather than presenting Computer Science as simply a programming discipline, the infographic communicates its broader role in:

```text
COMPUTATION
     +
PROBLEM SOLVING
     +
DATA
     +
SYSTEMS
     +
SECURITY
     +
INNOVATION
     ↓
DIGITAL SOCIETY
```

The goal is to make complex information **easy to understand without making it boring**.
